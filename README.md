One sentence of at most 200 characters explaining the modern internet to a time traveler arriving from the year 1800, built only from things they already know — a road, a library, a post office, a cottage, the sea.

> Imagine a road of glass and lightning joining every library and post office on earth, so a question asked in a cottage is answered before the kettle boils by a stranger across the sea.

## Run it

```sh
python3 main.py   # writes the sentence to /output/entry.txt
```

`main.py` uses only the Python 3.13 standard library and writes exactly one fixed sentence, deterministically.
